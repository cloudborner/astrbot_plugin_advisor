# 安全与隐私设计

## 信任边界

市场字段、GitHub 仓库名、路径、依赖包名、插件描述和大模型输出全部是不可信数据。
它们只能进入长度受限的结构化字段，不能成为系统命令、Python 代码、文件路径或自动安装指令。

## GitHub 凭据

- 生成完整索引时使用短期、只读公共仓库 Token。
- Token 只从 `GITHUB_TOKEN` 进程环境读取，不写入插件配置、缓存、索引、日志或命令输出。
- 扫描前检查 GitHub 是否给出 5000 的认证核心额度；否则退出且不覆盖索引。
- 扫描结束清除环境变量并撤销临时 Token。
- 不读取浏览器 Cookie、密码库或账号密码来代替 API Token。

## 提示注入防护

模型系统提示明确声明仓库事实是不可信引用材料，要求只返回固定 JSON。解析器拒绝额外字段、非法等级、超长数组和高于 0.70 的置信度。合并器逐维取确定性规则与模型结果的较高风险，模型不能把风险降级。

## 群聊隐私

统计默认开启，用户可随时关闭。启用时：

- 原文仅在当前事件内存中做关键词/计数分析，随后丢弃；
- 不持久化用户 ID、消息 ID、原文、URL 或明文群号，也不读取平台提供的昵称字段；聊天正文里达到阈值的称呼可能作为词项持久化，应按潜在敏感数据保护；
- 群号与平台、本地随机盐一起做 SHA-256，只保存截断摘要；
- 按日聚合并按配置自动过期；
- 相同规范化消息每天最多计入 3 次内容量，语义特征只计第一份，避免重放刷高主题；
- 只有至少由 2 条不同消息支持的词项、命令和共现才允许持久化或发送给模型；
- 模型只接收不超过 20 KiB 的去身份化结构化特征，输出的新需求必须引用输入特征 ID；
- 私聊不进入群统计。

聚合特征只会在用户运行相关推荐或分析命令时发送给配置的模型提供商，不会随每条消息被动外发。
若不希望任何群聊聚合数据离开服务器，请在普通配置页关闭“启用群聊需求分析”；若只想保留本地统计、
不调用模型，可手动把隐藏高级值 `enable_llm_group_summary` 设为 `false`。

## 签名索引

远程更新只接受 HTTPS 公网地址；拒绝 localhost、私网/保留 IP、DNS 解析到私网的主机以及所有 HTTP 重定向。manifest 先通过内置 Ed25519 公钥验证，再校验索引 SHA-256、大小、schema 和内部 checksum。下载成功后原子替换，旧文件保留 `.bak`；任一步失败继续使用旧索引。

签名私钥必须离线保存且永不进入插件包或生产服务器。

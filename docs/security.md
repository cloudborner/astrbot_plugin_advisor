# 安全与隐私设计

## 信任边界

群消息、图片引用、市场字段、GitHub 仓库内容、插件描述和模型输出全部是不可信数据。它们只能进入长度受限的结构化字段，不能成为系统命令、Python 代码、自动安装指令或任意本地路径。

插件只提供建议，不安装、卸载或执行候选插件。

## 群聊数据

- 只有QQ号白名单中的用户可以发起命令。
- 历史消息只在用户确认重新分析后读取。
- 平台组件、CQ码、卡片、base64、临时路径和长标识不会进入语义文本。
- QQ号替换为仅本次分析有效的匿名编号；昵称和明文群号不发送给模型。
- 邮箱、手机号、长数字、Token 和 Cookie 在进入模型前清理。
- URL 默认清理为链接类型或受限引用，不能被模型主动访问。
- 实时历史和分析草稿同时有每群与跨群全局消息、字符、图片和时间上限；同一操作者只保留最新草稿，确认、取消或超时后清除。
- 长期文件不保存模型看到的聊天原文。
- 私聊不会进入被动群统计。

`/导出聊天记录` 是独立的显式操作。导出文件可能包含聊天正文和发送者信息，不会自动交给模型。私聊导出默认只校验插件QQ号白名单；可开启管理员身份附加校验。白名单只应包含可信账号，导出文件应妥善保管和清理。

## 提示注入与证据约束

- 系统提示明确声明聊天、词组和图片说明是不可信数据。
- 聊天中的“忽略前文”、角色声明和命令不会改变插件任务。
- 模型只允许返回固定字段的 JSON。
- 每项需求必须引用输入中存在的消息或图片证据编号。
- 引用不存在的编号、返回额外字段、非 JSON、超长数组或非法置信度时结果无效。
- 模型不能推荐具体插件、决定分数、访问链接、调用工具或恢复真实身份。
- 超长聊天按有界窗口处理，不通过静默截断绕过证据校验。

## 图片与视频

- 图片默认最多选择 8 张，配置范围 1–20。
- 表情组件、base64、无效文件和重复图片会被排除。
- 本地图片按内容哈希去重；远程图片先按清理过临时签名的稳定引用去重，再按实际内容哈希去重。
- 远程图片只允许标准 HTTP/HTTPS 端口和公网地址；每次跳转都会重新检查，拒绝账号口令、内网、回环、保留地址和非标准端口。
- 图片使用流式读取，单张和单次总量都有上限，并校验 PNG、JPEG、GIF、BMP 或 WEBP 文件头；不会把所有图片一次性读入内存。
- 图片选择优先覆盖聊天时间线，并优先保留附近有文字语境的图片。任一图片失败不会中断全文分析。
- 校验过程只计算大小与哈希，不长期保存图片正文；模型调用结束后不保留图片临时副本。
- 图文调用失败时只允许一次文字降级。
- 插件不下载、抽帧、上传或识别视频，也不存在视频分析配置。

## 模型调用审计

启用日志时，每次正式分析只记录：调用开始与结束时间、总耗时、分阶段耗时、模型调用次数、Provider 返回时可获得的输入/输出/总 Token 数、原生 Schema 降级次数、是否重试、消息与图片数量、结果状态和结果摘要哈希。

审计文件有记录数量和文件大小上限，不包含聊天原文、QQ号、昵称、群号、图片内容、模型凭据或提供方内部名称。

## 安全检查点与重发

- 只有模型结果通过本地字段、证据编号和候选范围校验后才保存报告检查点；失败的原始模型输出不会写入。
- 检查点只保存报告所需的派生结论、需求证据摘要、推荐卡片和计数，不保存原始消息、账号、昵称、群号、完整提示词、模型原始输出或图片内容。
- 群索引使用安装级随机盐进行 HMAC，不保存明文群号；重发时从当前已授权命令上下文恢复群号小字。
- 每群只保留最近一份，默认24小时失效，全局数量和文件大小均有限制。
- 私聊查询或重发始终校验插件QQ号白名单；“私聊操作要求本人在群内”默认关闭，开启后才会验证操作者和机器人均属于目标群。群聊只能操作当前群。

## GitHub 与资源索引

- 插件运行时优先读取官方市场和随版本发布的离线资源画像，不在低内存服务器批量下载全市场源码。
- 新插件缺少画像时，只读取公开仓库的受限元数据、目录和必要文件，执行确定性静态规则。
- 模型资源复核只能提高风险，不能无证据降低风险。
- 插件运行时 GitHub 客户端不隐式读取进程环境凭据；离线索引扫描脚本可以显式读取 `GITHUB_TOKEN`，但不会把它写入插件配置、缓存、索引、日志或命令输出。
- 不读取浏览器 Cookie、密码库或账号密码来代替 API 凭据。
- 此前在聊天中暴露的旧令牌不得用于发布或服务器部署。

## 日志与文件写入

- 日志默认开启，但只记录状态、数量、耗时和不含原文的错误摘要。
- 分析统计、审计、安全检查点和迁移采用有界、原子写入。
- 数据迁移先保存旧文件备份，失败时不覆盖可恢复数据。
- 报告渲染对所有可见内容进行转义；渲染失败自动回退纯文字。
- 群号只作为报告小字标注；如果 AstrBot 使用远程图片渲染，该标注和派生报告内容会进入配置的渲染端点。

# 插件顾问配置说明

插件安装后，在 AstrBot WebUI 的插件配置页中编辑。插件只提出建议，不会自动安装、更新或执行候选插件。

## 普通设置

| 配置 | 默认 | 作用 |
| --- | ---: | --- |
| QQ号白名单 | 空 | 只有列表中的QQ号可以发起分析；为空时拒绝所有人。 |
| 群需求分析模型 | 当前会话模型 | 留空时使用当前会话模型；没有模型时不能完成正式需求分析。 |
| 分析图片内容 | 开启 | 当前分析方式支持图片时结合图片理解需求，否则自动改为文字分析。 |
| 每次推荐数量 | 8 | 范围 1–20；没有可靠候选时不会凑满。 |

## 高级设置

| 配置 | 默认 | 范围或作用 |
| --- | ---: | --- |
| 默认显示词组数量 | 15 | 范围 5–50；隐藏词组仍参加分析。 |
| 单次分析图片上限 | 8 | 范围 1–20；按聊天时间分散选择。 |
| 自定义黑名单词汇 | 空 | 在内置平台噪声过滤之外追加要忽略的词组。 |
| 自定义黑名单正则 | 空 | 追加固定格式过滤；无效、危险或过长规则会被忽略。 |
| 单次历史读取上限 | 1000 | 范围 100–5000，同时限制分析和手动导出。 |
| 最少有效消息数 | 30 | 范围 5–1000，低于门槛不创建分析草稿。 |
| 统计数据保留天数 | 30 | 范围 1–365。 |
| 最低推荐分 | 40 | 范围 0–100。 |
| 报告详细程度 | 标准 | 精简只显示证据摘要；标准附少量证据编号；详细展示完整证据编号、更多评分依据和模型不确定项。 |
| 发送图片报告 | 开启 | 渲染失败时自动改发纯文字。 |
| 模型最长等待时间 | 45 秒 | 范围 5–120，限制每次模型调用；超出范围会钳制并写入 AstrBot 日志，完整分析与候选复核另有内部总处理时限。 |
| 记录运行日志 | 开启 | 写入 AstrBot 统一日志，只记录阶段、状态、数量、耗时和脱敏错误原因。 |
| 复核新插件资源风险 | 关闭 | 资料不足时允许模型保守提高资源风险。 |

市场地址、GitHub 回退、签名索引、公钥、缓存、评分权重和安全限额由插件内部维护，不作为用户配置。最终需求分析必须使用模型，因此也不提供“关闭模型理解群需求”的选项。

## 分析流程

1. 白名单用户发起 `/需求分析`，群聊分析当前群，私聊需要指定目标群。
2. 用户确认重新读取后，插件分页读取历史，排除机器人消息并清洗平台组件。
3. 插件去重、去身份化并提取词组，建立短期草稿。
4. 词组确认页默认显示前 15 项，此阶段绝不调用模型。
5. 用户可以分页查看、修改或删除词组。
6. 用户执行 `/确认分词` 后，插件才把去身份化连续上下文、有效词组和有限图片交给模型。
7. 超长内容按连续窗口分析，每段结果必须引用真实证据编号，最后再综合。
8. 模型只在本地初筛候选中复核功能适配和风险；本地代码校验候选与证据、排除已安装插件，再结合服务器、市场和资源画像完成固定评分并生成报告。

草稿绑定调用者和目标群，默认保留约 30 分钟。同一调用者开始新分析时会替换尚未确认的旧草稿；确认、取消或超时后，临时聊天上下文会被清除。实时历史和草稿还有跨群全局容量限制。

## 模型与本地评分的边界

模型负责理解群用途、主要需求、适合的机器人能力、不适合的能力和不确定性。每项需求必须引用输入中的消息或图片证据编号。

第一次需求分析不能选择插件ID。候选复核阶段只能在本地提供的有限候选中判断适配程度，不能新增候选。模型不能决定总分、修改评分权重、调用工具、访问聊天中的链接或触发安装。聊天和插件资料中的命令与角色声明都只是数据。

本地代码负责插件市场读取、候选范围、证据编号校验、已安装插件排除、资源风险、兼容性、冲突和最终评分。任一模型阶段没有成功调用、输出结构错误、选择候选范围外插件或引用不存在的证据时，不会生成伪造的“模型分析成功”推荐。

私聊分析指定群时，插件会同时确认机器人和操作者都是目标群成员。私聊导出原始聊天记录的权限更严格，仅允许目标群群主或管理员；权限接口不可用时默认拒绝，不会先读取历史再判断。

## 固定评分

推荐总分固定为：群聊需求 30、市场使用 20、平台与版本兼容 20、资源适配 15、维护活跃 10、部署复杂度 5。市场使用的 20 分由累计下载 12 分和 Stars 8 分组成。配置页不提供修改权重入口。

## 旧版迁移

仍有意义的旧用户配置会继续读取。市场地址、索引更新、自定义主题、旧滑动分词和调试权重不会继续影响运行。

旧分析数据首次加载时会备份原文件，保留基础数量统计，清除旧词频、共现碎片、主题推断和历史去重状态。下一次分析会重新读取目标群历史并使用新清洗器建立草稿。

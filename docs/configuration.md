# 插件顾问配置说明

插件安装后，在 AstrBot WebUI 的插件配置页中编辑。插件只提出建议，不会自动安装、更新或执行候选插件。

## 普通设置

| 配置 | 默认 | 作用 |
| --- | ---: | --- |
| 自动确认分析 | 开启 | 准备报告送达后倒计时并自动分析；关闭使用手动词组确认。 |
| 自动确认等待秒数 | 5 | 范围1–600；只在发送报告且自动确认开启时使用。 |
| 直接分析，跳过准备报告 | 关闭 | 开启优先于自动确认设置，只发开始提示，准备后直接排队，无中间报告及倒计时。 |
| QQ号白名单 | 空 | 只有列表中的QQ号可以发起分析；为空时拒绝所有人。 |
| 私聊操作要求本人在群内 | 关闭 | 关闭时，私聊分析、查询和重发只校验插件白名单；开启后还会校验调用者已加入目标群。 |
| 私聊导出要求本人为群管理员 | 关闭 | 关闭时，私聊导出只校验插件白名单；开启后还会校验调用者是目标群群主或管理员。 |
| 群需求分析模型 | 当前会话模型 | 留空时使用当前会话模型；没有模型时不能完成正式需求分析。 |
| 分析图片内容 | 开启 | 当前分析方式支持图片时结合图片理解需求，否则自动改为文字分析。 |
| 每次推荐数量 | 8 | 范围 1–20；没有可靠候选时不会凑满。 |

## 高级设置

| 配置 | 默认 | 范围或作用 |
| --- | ---: | --- |
| 默认显示词组数量 | 15 | 范围 5–50；隐藏词组仍参加分析。 |
| 单次分析图片上限 | 8 | 范围 1–20；按聊天时间分散选择。 |
| 自定义黑名单词汇 | 空 | 在内置平台噪声过滤之外追加要忽略的词组。 |
| 自定义黑名单正则 | 空 | 追加固定格式过滤；无效、危险或过长规则会被忽略。 |
| 单次历史读取上限 | 1000 | 范围 100–5000，同时限制分析和手动导出。 |
| 排除机器人自己发送的消息 | 关闭 | 关闭时保留机器人回复并标记来源；开启后才从需求分析和历史回填统计中排除。 |
| 最少有效消息数 | 30 | 范围 5–1000，低于门槛不创建分析草稿。 |
| 统计数据保留天数 | 30 | 范围 1–365。 |
| 最低推荐分 | 35 | 范围 0–100；部分匹配但值得尝试的候选可以进入报告，并显示证据与风险。 |
| 报告详细程度 | 标准 | 精简只显示证据摘要；标准附少量证据编号；详细展示完整证据编号、更多评分依据和模型不确定项。 |
| 发送图片报告 | 开启 | 渲染失败时自动改发纯文字。 |
| 模型最长等待时间 | 45 秒 | 范围 5–120，限制每次模型调用；超出范围会钳制并写入 AstrBot 日志，完整分析与候选复核另有内部总处理时限。 |
| 记录运行日志 | 开启 | 写入 AstrBot 统一日志，只记录阶段、状态、数量、耗时和脱敏错误原因。 |
| 复核新插件资源风险 | 关闭 | 资料不足时允许模型保守提高资源风险。 |

市场地址、GitHub 回退、签名索引、公钥、缓存、评分权重和安全限额由插件内部维护，不作为用户配置。最终需求分析必须使用模型，因此也不提供“关闭模型理解群需求”的选项。

## 分析流程

1. 白名单用户发起 `/需求分析`，群聊分析当前群，私聊需要指定目标群；命令会直接进入历史读取，不再重复询问确认。
2. 插件分页读取历史，按高级设置决定是否排除机器人消息，并清洗平台组件。
3. 插件保留真实重复发言、去身份化并提取词组，建立短期草稿；只防止 OneBot 分页重叠或事件重复投递把同一条消息重复计入。
4. 默认发送准备摘要图片，送达后等待5秒自动继续；图片失败降级文字，两种发送都失败则停止。准备与等待阶段不调用模型。
5. 查看、有效修改或删除词组会暂停倒计时，转为手动确认。关闭自动确认时直接使用原词组确认页。开启直接分析时跳过准备报告和等待。
6. 倒计时到期或用户执行 `/确认分词` 后，插件领取一次启动资格，固定输入并排队，把去身份化连续上下文、有效词组和有限图片交给模型。
7. 超长内容按连续窗口分析，每段结果必须引用真实证据编号，最后再综合。
8. 模型只在本地初筛候选中复核功能适配和风险；本地代码校验候选与证据、排除已安装插件，再结合服务器、市场和资源画像完成固定评分并生成报告。
9. Provider 支持时使用原生严格 JSON Schema；只有明确返回“不支持 response_format/json_schema”时才退回提示词契约，本地证据校验始终执行。
10. 有效模型结果会生成一份24小时安全检查点。群内可用 `/最近需求分析` 查询、`/重发需求分析` 免 Token 重发；私聊命令需追加群号，是否额外检查群成员权限由普通设置中的开关决定。

草稿绑定调用者和目标群，未确认时保留约30分钟。同一调用者在同一平台实例中只能有一个任务；重复发起不会替换任务。模型执行并发仍限制为1，排队不消耗模型阶段时限。群内只能取消本人同群任务，私聊可取消本人当前实例任务。准备、渲染、倒计时、排队、模型和报告阶段都可取消，运行超过草稿有效期仍可取消。

取消不会撤销提供商已接收请求的费用，但会阻止后续调用和迟到报告。关闭或重载插件会停止任务；重启不自动恢复分析。任务结束后释放临时上下文，既有去身份化安全检查点仍按24小时规则保留。

## 模型与本地评分的边界

模型负责理解群用途、主要需求、适合的机器人能力、不适合的能力和不确定性。每项需求必须引用输入中的消息或图片证据编号。

第一次需求分析不能选择插件ID。候选复核阶段只能在本地提供的有限候选中判断适配程度，不能新增候选。模型不能决定总分、修改评分权重、调用工具、访问聊天中的链接或触发安装。聊天和插件资料中的命令与角色声明都只是数据。

本地代码负责插件市场读取、候选范围、证据编号校验、已安装插件排除、资源风险、兼容性、冲突和最终评分。无害的空项、换行或描述超长会被清理；综合模型输出校验失败时，可以只合并已经通过证据校验的分段结果。选择候选范围外插件或引用不存在的证据仍会被拒绝，不会生成伪造的“模型分析成功”推荐。

私聊指定群时始终先校验插件QQ号白名单。两个附加权限开关默认关闭，因此默认不查询调用者的群成员身份；机器人仍必须在目标群中并能读取历史。开启“私聊操作要求本人在群内”后，分析、最近报告和重发会确认机器人与调用者都在目标群；开启“私聊导出要求本人为群管理员”后，私聊导出只允许目标群群主或管理员。已开启的权限检查在接口不可用时默认拒绝，并且不会先读取历史再判断。

## 固定评分

推荐总分固定为：群聊需求 30、市场使用 20、平台与版本兼容 20、资源适配 15、维护活跃 10、部署复杂度 5。市场使用的 20 分由累计下载 12 分和 Stars 8 分组成。配置页不提供修改权重入口。

## 旧版迁移

0.12.0 新增 `general.auto_confirm_analysis=true`、`general.auto_confirm_delay_seconds=5`、`general.skip_preparation_report=false`。旧配置缺少字段也采用新默认值；如需保留手动确认，升级前在配置中显式设置 `auto_confirm_analysis=false`。改变配置并重载后生效，不修改已运行任务的模式。

仍有意义的旧用户配置会继续读取。市场地址、索引更新、自定义主题、旧滑动分词和调试权重不会继续影响运行。

旧分析数据首次加载时会备份原文件，保留基础数量统计，清除旧词频、共现碎片、主题推断和历史去重状态。下一次分析会重新读取目标群历史并使用新清洗器建立草稿。

## 活跃分析容量（0.12.1）

活跃任务按消息、图片、字符和条目数统一核算，包含倒计时、手动等待、排队、运行及仍在退出的任务，不能因草稿过期或旧存储淘汰而绕过。达到上限时拒绝新任务，不调用模型。字符预算预留词组编辑与快照余量；消息和图片快照共享不可变数据。准备过程串行，取消分词时等待不可强制终止的线程释放准备槽，取消命令仍有界返回，迟到结果不会继续调用模型。

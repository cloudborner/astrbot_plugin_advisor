# 插件顾问

插件顾问会阅读去身份化的群聊内容，理解群里真正需要哪些机器人能力，再结合服务器余量、插件市场、资源占用、兼容性、维护情况和已安装插件给出建议。

它只提供建议，不会自行安装、更新或删除插件。

运行要求：AstrBot 4.26.7 或更高版本，兼容当前 4.26 系列和 5.x。

## 安装和首次设置

从 AstrBot 插件市场安装后，在配置页完成以下设置：

1. 在“QQ号白名单”中填写允许使用插件的QQ号。
2. 选择“群需求分析模型”，或留空使用当前会话模型。
3. 保存配置并重新加载插件。

图片内容分析默认开启，也可以按群的实际情况调整推荐数量。白名单为空时，所有人都无法使用插件顾问命令。

## 分析当前群

在群里发送 `/需求分析`，插件会询问是否重新读取最新聊天。

确认后，插件读取历史消息并生成词组确认页。此时模型还没有被调用。你可以先检查词组，再决定是否继续：

| 命令 | 作用 |
| --- | --- |
| `/显示全部分词 [页码]` | 分页查看默认隐藏的其他词组。 |
| `/修改分词 <序号> <新词组>` | 修正一个词组，编号保持不变。 |
| `/删除分词 <序号>` | 删除不应参加分析的词组。 |
| `/确认分词` | 确认词组并开始模型分析。 |
| `/取消分析` | 清除本次临时草稿。 |

只有执行 `/确认分词` 后，模型才会读取本次去身份化聊天并生成插件建议。

## 在私聊中分析群

白名单用户可以在私聊中使用 `/需求分析 <群号>` 选择目标群。机器人必须已经加入该群，并且当前平台能够读取群历史。

后续的词组查看、修改、删除和确认方式与群内分析相同。草稿会同时绑定调用者和目标群，不能用于其他群。
同一调用者再次开始其他群的分析时，会用新草稿替换尚未确认的旧草稿，避免私聊命令误操作到旧目标群。

## 图片分析

- 图片分析默认开启，默认最多选择 8 张。
- 图片会在聊天时间范围内分散选择，并自动去除重复或无效引用。
- 当前分析方式能够查看图片时，报告显示“图文分析”和实际分析数量。
- 当前分析方式不能查看图片时，插件会继续进行文字分析，并在报告中明确说明图片未被分析。
- 单张图片失效不会中断整个分析。
- 插件不会下载、抽帧、上传或识别视频；视频只计入消息数量统计。

## 推荐结果怎么看

推荐分综合考虑群需求、市场使用情况、AstrBot 兼容性、服务器资源、维护状态、部署难度、外部服务和插件冲突。

候选检索会同时使用市场说明、分类、标签和内置功能语义索引。功能语义索引由市场资料和确定性分类生成，记录来源、版本与置信度；它只帮助找到可能相关的候选，不能代替群聊证据。候选仍需经过模型功能复核，资料不足时可以不推荐。

资源占用分为四档：

- 轻量：通常适合低配置服务器。
- 一般：使用时可能出现一定峰值。
- 较高：低内存服务器需要谨慎。
- 重型：可能包含本地模型、浏览器、媒体处理或较重后台任务。

资源档级来自源码与公开资料的安装前估计，不等同于真实运行时测量。资料不足的新插件会标记为“估计”或“未知”。

已经安装的同一插件、同仓库插件或重复分支会自动排除。如果现有插件已经覆盖主要需求，报告会直接说明，不会为了凑数量继续推荐。

## 其他命令

| 命令 | 作用 |
| --- | --- |
| `/插件体检` | 查看服务器余量和资源资料状态。 |
| `/插件推荐 [关键词]` | 引导进入完整需求分析流程，不会跳过分词确认。 |
| `/插件风险 <插件名>` | 查看一个插件的资源和兼容性风险。 |
| `/资源画像 <插件名>` | 查看插件资源画像。 |
| `/插件对比 <插件A> <插件B>` | 比较两个插件。 |
| `/插件分类 [分类]` | 查看插件分类。 |
| `/插件排行 [页码]` | 查看不包含群聊需求的市场与服务器基础排行。 |
| `/导出聊天记录 [群号] [数量] [格式]` | 群内导出当前群；私聊指定群时仅限该群管理员或群主。 |

导出格式支持 JSON、JSONL 和 TXT。导出文件包含聊天正文，只应由有权限的管理员使用，完成后请妥善保存或删除。

## 隐私和日志

- 模型只接收去身份化且有长度上限的分析内容，不接收QQ号、昵称、明文群号或凭据。
- 临时聊天上下文会在确认、取消或超时后清除；长期文件不保存聊天原文。
- 报告只在末尾标注群号；使用远程图片渲染时，报告内容会发送到 AstrBot 配置的渲染端点。
- 插件日志直接写入 AstrBot 统一日志，只记录阶段、状态、数量、耗时和安全错误原因，不记录聊天原文、账号或模型输出。

## 卸载与数据

卸载插件不会自动删除已经导出的聊天记录。插件运行数据和导出文件位于 AstrBot 为插件分配的数据目录中；确认不再需要后，可由管理员手动删除。

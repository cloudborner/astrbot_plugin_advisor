# 插件顾问

不知道群里适合装什么插件？插件顾问会结合群聊中经常讨论的内容、当前服务器配置和插件市场数据，给出更适合你的推荐，并提醒可能的内存、CPU、磁盘和兼容性问题。

它只提供建议，不会自行安装、更新或删除任何插件。

运行要求：AstrBot 4.26 或更高版本。

## 能做什么

- 根据群聊话题发现真实需求，例如 RoboMaster、游戏攻略、下载工具、群管理或角色陪伴。
- 从插件市场中筛选更合适的插件，并按推荐度排序。
- 安装前查看插件可能带来的内存、CPU、磁盘和网络压力。
- 比较两个插件，帮助你选择更适合当前服务器的一个。
- 查看插件分类和完整排行，了解市场中还有哪些选择。
- 检查服务器余量，避免在低配置机器上叠加多个高占用插件。

## 开始使用

安装后先在配置中的“QQ号白名单”加入允许使用插件的QQ号，再保存配置。白名单为空时，所有人都无法调用插件命令。

插件会从启用后收到的群消息中整理需求数据。默认累计至少 30 条有效消息后，模型才会参与分析；消息不足时仍可查看基础统计。

在群里发送 `/需求分析` 后，插件会先询问是否重新分析。确认后发送 `/需求分析 确认`，插件会忽略上一次模型结果，重新生成当前群的需求报告。

白名单用户也可以在私聊中发送 `/需求分析 群号`，确认后发送 `/需求分析 群号 确认`，直接查看指定群的报告。机器人必须已经加入该群并采集到需求统计数据。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/插件体检` | 查看服务器余量和资源资料状态。 |
| `/插件推荐 [关键词]` | 推荐适合当前群和服务器的插件，也可以指定关键词。 |
| `/需求分析 [群号]` | 群聊中分析当前群；私聊中填写群号分析指定群。 |
| `/插件风险 <插件名>` | 查看插件可能的资源占用和风险。 |
| `/资源画像 <插件名>` | 与“插件风险”作用相同。 |
| `/插件对比 <插件A> <插件B>` | 比较两个插件。 |
| `/插件分类 [分类]` | 查看插件类型或某类插件。 |
| `/插件排行 [页码]` | 查看完整市场排行。 |

报告默认以图片发送；图片生成失败时会自动改发文字。

## 怎样看推荐结果

推荐分由群需求、市场使用情况、兼容性、资源适配、维护情况和安装难度共同组成。分数越高，表示越值得在当前群和服务器上尝试，不代表插件本身绝对优劣。

资源占用分为 L0–L4：

- L0：没有发现明显压力，或现有资料不足。
- L1：轻量，通常适合低配置服务器。
- L2：中等，使用时会有一定峰值。
- L3：较高，低配置服务器需要谨慎。
- L4：很高，常见于本地模型、浏览器、视频转码等功能。

这些等级来自源码和公开资料分析，是安装前的风险估计，不是实机性能测试。

## 配置

常用设置包括：

- 哪些QQ号可以使用插件命令。
- 是否记录群聊需求数据。
- 每次推荐多少个插件。
- 报告显示多少细节。
- 使用哪个模型理解群需求。

展开“高级设置”还可以调整：

- 是否优先发送图片报告。
- 是否记录日志。
- 至少收集多少条消息后再分析。
- 需求数据保留多少天。
- 最低推荐分。
- 是否使用模型理解群需求或复核资料不足的插件。
- 模型分析最长等待时间。

## 数据与隐私

插件不会保存完整聊天原文、QQ 号或明文群号，只保存按天整理的词频、话题关系和需求计数。模型只会收到整理后的摘要，不会收到完整聊天记录。

QQ号白名单只用于命令鉴权，不会写入群需求统计或发送给模型。插件仍会统计群内所有成员的去身份化聚合特征，否则只分析白名单成员会导致群需求失真。

关闭“启用群聊需求分析”后，插件不会继续记录新的群需求数据。已经保存的数据会按设置的保留天数自动清理。

## 使用提醒

- 推荐结果不会自动触发安装。
- 新插件或资料不足的插件可能判断不准，应结合风险说明查看。
- 同时安装多个 L3/L4 插件可能导致低内存服务器卡顿或 OOM。
- 遇到问题时可保持“记录日志”开启，方便定位原因。
